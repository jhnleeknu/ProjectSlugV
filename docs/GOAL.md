# 메탈슬러그 5 전체 추출·분석 및 C++ 재구성

제공된 ROM에서 미사용 데이터를 포함한 전체 리소스와 엔진·게임 로직을 추출·분석하고, 추출 리소스를 사용하는 실행 가능한 C++ 프로그램으로 재구성한다. 결과는 원본과 대응 관계가 있고 재현·검증 가능해야 한다.

## 1. 원본과 분석 기반
- 버전·해시를 확인하고 원본을 보존한다.
- 복호화된 프로그램·그래픽·사운드를 확보한다.
- 역어셈블 결과를 보존하고 코드·데이터 영역을 구분한다.
- ROM 오프셋, CPU 주소, 뱅크와 재구성 코드의 대응을 기록한다.
- 영역별 추출·해석·검증 현황과 미해결 항목을 관리한다.

## 2. 리소스
- 그래픽 타일, 스프라이트, 팔레트, 사운드를 추출한다.
- 애니메이션 조각 배치, 기준점, 프레임 시간, 팔레트 선택을 해석한다.
- 맵, 오브젝트 배치, 충돌 데이터, 스테이지 이벤트를 분석한다.
- 미사용 데이터도 보존하고 사용 여부가 불확실하면 미확인으로 표시한다.
- 원시 데이터와 해석·변환 결과를 함께 유지한다.

## 3. 공통 규격
- 추출 도구와 엔진이 공유하는 버전 있는 규격과 안정적인 ID를 정의한다.
- 각 리소스의 원본 위치, 추출 방법, 관련 테이블을 기록한다.
- 메타데이터는 JSON을 기본으로 하고 이미지·오디오·대용량 데이터는 적합한 별도 파일로 저장한다.
- 규격 변경 시 도구와 엔진을 함께 갱신한다. 임의의 별도 규격을 만들지 않는다.

## 4. 엔진과 로직
- 메인 루프, 입력, 렌더링, 오브젝트 관리, 이동, 충돌, 무기, 적·보스 AI, 스테이지 이벤트, 사운드 제어를 분석·구현한다.
- 복원한 로직이 추출 리소스를 실제로 사용하도록 연결한다.
- 정수 연산, 부호, 오버플로, 좌표 정밀도, 갱신 순서, 난수와 타이밍을 확인하여 재현한다.
- 하드웨어 의존 동작을 별도 계층으로 분리한다.
- 미사용 데이터의 존재와 실제 실행 가능한 기능을 구분한다.
- 원본 개발 소스의 변수명·주석을 되찾았다고 주장하지 않는다.

## 5. 구현과 협업
- AGENTS.md의 C++11 기본 문법·Python 규칙과 역할 분담을 따른다.
- 복잡한 추론·설계·리뷰·통합·최종 정리는 메인 에이전트가 직접 담당한다.
- 노동집약적인 구현·검증·문서화·PR 초안은 gpt-6.1-sol / medium 서브에이전트에 위임한다.
- 반복 처리는 스크립트화하고 독립된 작업만 병렬화한다.
- 로컬 Git에서 코드·도구·규격·분석·리뷰 기록을 관리한다.
- 원격 연결 후 PR로 변경과 검증을 정리한다. 원격이 없을 때는 로컬 리뷰로 진행한다.

## 6. 진행 순서
1. ROM 검증과 전체 데이터 확보.
2. 공통 규격 정의 및 대표 리소스 추출.
3. C++ 런타임에서 대표 오브젝트의 표시·애니메이션·이동 검증.
4. 엔진 주요 구조와 게임 로직의 단계적 복원.
5. 전체 스테이지·오브젝트·사운드로 확대.
6. 미사용 리소스와 미해결 코드 조사.

각 단계의 통합 결과를 검증한 후 범위를 확장한다.

## 7. 완료 기준
- 원본에서 결과물을 재생성하는 도구·명령을 제공한다.
- 빌드 가능한 C++ 소스와 실행·조작 방법을 제공한다.
- 동일한 초기 조건·입력으로 에뮬레이터의 상태·실행 기록·화면·사운드와 비교한다.
- 사실·추론·미확인을 구분하고 주소·참조·실행 관찰을 근거로 남긴다.
- 덤프·자동 역어셈블·일부 스프라이트 표시·한 스테이지 실행만으로 전체 완료를 선언하지 않는다.
- 전체 범위의 추출·해석·동작 검증이 끝나고 목표에 필요한 미해결 항목이 해소되어야 완료다.
- 메인 에이전트의 리뷰, 필요한 수정, 재검증과 최종 문서 정리를 완료한다.
- 진행 상태·검증 결과·남은 문제·다음 작업을 지속적으로 저장한다.
