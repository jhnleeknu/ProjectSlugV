- [U] 정적 참조 색인은 정적 발견기가 닿은 코드만 본다(`c5370` `76ff2` `7706a` 등은 LONG 표·`MOVEA.L #` 상수로만 닿아 "참조 없음"). 재분류는 참조가 있는 root에만 적용했다.
- [U] TB 시작 PC 중 block 시작이 아닌 것(예 FR3의 `76ff8` `d0fee`)은 Unicorn TB 경계다: 단위 정의에서 진입으로 쓰지 않는다.
