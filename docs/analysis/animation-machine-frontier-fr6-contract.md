# frontier 단위 FR6(FR5 뒤 마지막 C 무관 D frontier `50dae` 묶음과 FR7 앞부분) 구현 계약

**구현 전 계약 — 작업자(Claude Opus 5.5 / high) 초안.** 이 문서를 먼저 쓰고 그대로 구현한다. FR2·FR2b·FR3·FR4·FR5 계약(`animation-machine-frontier-fr5-contract.md`)의 구조·공통 규칙을 따르고 다른 점만 적는다. 메인 지시: `area-d-completion-plan.md`(맨 위 메인 결정) §4의 FR6 = `50dae` 묶음(약 105 block, 3 run frame 271, IO 집합의 마지막 C 무관 D: FR5 뒤 `dleft.py`의 C 무관 D PC 24개가 모두 이 묶음)을 FR7 앞부분(C 뒤에만 IO에 나타나는 D; native 실행 수가 큰 root, 자연스러운 closure)으로 약 220 이하까지 채운다. FR6 뒤 IO 집합의 D 첫 정지는 0이어야 한다(예측 165,714). `50dae` run의 자연 후속은 들어가는 한 600 frame까지 따라간다. 계산 표는 모두 전사하고 TRAP 자리는 checked 경계다. FR7 앞부분 root는 C 앞에서 IO로 닿지 않으므로 단위 시험·V1이 스스로 선다(선언 상태). 결정 항목은 작업자 권고안으로 구현하며 메인이 바꾸면 그에 맞춰 고친다.

## 결정

1. **범위.** FR6 = `50dae` 묶음 105 + FR7 앞부분 115 = **220 block**(21 범위). FR7 앞부분은 C 뒤 D root 중 native 실행 수가 큰 순서의 자연 closure(`4855c` `19a00` `d764a` 객체 `36292` 객체, 작은 helper `1aa66` `1a988` `e9148` `49c38`, `72978` 객체와 `703f6`, `4fcb8`, `48210`, `e625e`)다. 220을 넘기는 `4ab88`/`4ad6c`(109)는 FR7에 남긴다.
2. **계산 점프·표.** 이 단위에 계산 점프가 없다(전사할 점프 표 0). 자료 표 `d75ce`(LONG 15개, 위 전사)·`4411e`(WORD, 색인 ≤ `1fe`)·소리 대본 `50e80`은 live bus 읽기이고 표 밖 색인도 원본대로 읽는다. TRAP 자리 없음.
3. **carry 보존 목록.** 소비자 12개. `51054`는 두 직전 block(`51044` Clear, `51050` Set)의 known C를 받는다. `50f62`(SCC 뒤 `MOVE.W`)는 끝에서 Clear다. C를 넘기는 `RTS` 없음(생산자 RTS 6개는 자기 C).
4. **설치 값.** `MOVE.L #v,(A6)`은 v가 바로 다음 PC일 때만 그 block으로 들어간다. 쓰기만: `50cf6`(두 곳) `d7766` `d76a6` `510d0` `511ae` `70c0c` `71c90`.
5. **숨은 탐침 이전.** `fr1b_test`의 `e9148` → `10fe78`, `scheduler_test`의 `4fccc` → `10fe7c`(F4 단위 시험 경계 규칙). legacy Python 검증기 2개는 목록만(위). stage_event / stage_event_ops `CPP_PINS` 갱신은 메인이 검증 단계에서 정한다.
6. **C 뒤 root의 검증.** FR7 앞부분 root는 선언 상태(seed world + 선언 편집)만으로 단위 시험·V1·실제 ROM 차분을 한다. IO pack 자연 상태로 V1을 만드는 것은 하지 않는다(spec이 IO pack을 해독하지 않음; IO 비교의 확인은 C·E 연결 뒤, 계획 메인 결정).
7. **F4 범위 문서.** R07(`7282c..72e8a`)·R12(`70054..70a64`)·U14 계획 범위(`50cca..50dac`)는 이 단위의 `72978..72a10` `703f6..70418` `50cf6..50d2c`를 빼야 한다.
8. **정적으로 불가능한 분기.** `5100c BMI` → `51014`(`50ffe`의 D0.W = WORD − 같은 WORD = 0). V1 spec `STATIC_IMPOSSIBLE`.
9. **다음.** 이 단위 뒤 IO 집합의 D 첫 정지 0(예측 165,714). 남은 D 262 PC는 모두 C 뒤(FR7..FR9).
