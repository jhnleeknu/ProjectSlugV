# `480bc` 프레임 helper 묶음 U2: 장면 core `1a73c` 계약

Baseline: U1 계약(`animation-machine-frame-helpers-u1-contract.md`) 작성 시점의 작업 트리. 범위 근거는 `animation-machine-480bc-scope.md`의 U2. Claude Opus 5.5 / high 분석 작업자가 canonical BE ROM(SHA256 `29112a94b5c073de95919ab4efbc75427287739eab794ef442d2aa7c886c860f`, `extracted/program/maincpu.decrypted.be.bin`, fixed CPU 주소=file offset)을 capstone M68000으로 디코드하고 기존 Unicorn 관측 산출물을 읽기 전용으로 재생해 작성했고, 메인(Claude Opus 5.5)이 원본 바이트 대조 리뷰 뒤 아래 결정을 반영해 확정했다. 이 문서는 구현·원본 동등성 완료 보고가 아니다. [F]=원본 바이트 또는 기록된 산출물에서 확인한 사실, [I]=추론, [U]=미확인. 명령 단위 정답은 원본 바이트 자체다.

메인 결정: (1) 비null motion 경계는 선택 A(`19812`/`19844`/`19910` 분기 대상에서 stop)로 확정한다. (2) 조건 index는 아래 정책대로 원본 계산 PC를 따른다.
