# 팔레트 효과 리뷰

기준6cb6960 이후. 메인이479e/504c의 byte래핑·부호검사·상한처리와 순서를 해석했다. 확정사양의 C++ 반영은 gpt-6.1-sol medium에 위임하고 메인이 diff/원본 비교를 검토했다.

- signed덧셈clamp로 단순화하지 않고 byte wrap 후 sign 검사를 유지한다.
- 혼합 후 효과를 적용하고 효과우회는 기존hardware 경로를 보존한다.
- 원본helper9248조건, 실제MS5P825조건 일치.
- 전체검사 및 일반혼합660조건 회귀 통과.
- 중간혼합 source bit15는 여전히 미검증입력으로 거부한다. 효과/혼합계수의 실제갱신 흐름은 후속작업이다.
