# 포맷터·스테이지 그룹 콜백 전체 레지스터 리뷰

대상 기준 커밋: `1cc711c`.

메인이 397c의 D3 word 읽기, 38ce의 전체 초기화와 9802의 이벤트별 D1/D3 동작을 분석하고 구현했다. 파서의 위치 제어 실행 여부를 포맷 본문과 문자열 인자에 걸쳐 누적하며 성공 시에만 레지스터를 반영한다. event3의 D1은 byte 순환 좌표, event5의 D1은 상위가 지워진 최종 style이다. 기존 호출 방식은 유지한다.

서브에이전트는 CLI와 독립 원본 비교기를 담당했다. 메인이 실제 diff, 오류 보존, 정수 범위, 원본 불변 검사와 반복 입력의 출처를 검토했다. 여섯 스테이지 콜백 흐름은 실제 C++ 출력 RAM과 JSON을 다음 호출로 전달한다. 새 CLI는 MS5D 런타임 리소스를 읽으며 포트 파일은 진단용이다.

- `make -j3 all test`: 종료 0, Python 73개와 C++ 전체 검사 통과, 컴파일 경고 없음. 로그 `artifacts/stage_group_registers_build_test.log`.
- `.venv/bin/python tools/verify_formatted_registers.py`: 914조건, 포트 5,392개, 출력 보존 오류 검사 18조건 통과. 보고서 SHA256 `8ccc6d16fd27b94fc32b2717d14c47b5ab96bd57a335270b8b2026158608f673`.
- `.venv/bin/python tools/verify_stage_group_registers.py`: 1,208조건, 포트 12,588개, 출력 보존 오류 검사 31조건 통과. 보고서 SHA256 `062aff35044fe73111a4ef14a3224a939ec95d57d75dcfdb070a5aee22828d2b`.

검증 중 `%s` 문자열 줄바꿈/CURSOR=ffff의 원본 TRAP #15를 발견했다. 정상 반환 행렬에서 제외하고 C++의 오류·출력 보존을 별도 검증했다. 예외 핸들러 실행은 미복원이다. 문자열 끝 제어문자가 첫 NUL을 소비하는 원본 동작 때문에 해당 fixture는 명시적으로 이중 NUL을 둔다. 임의의 후속 메모리 동작을 포괄하지 않는다.

짧은 폰트 창을 오류로 간주한 검증 가정도 수정했다. 해당 row0/event5는 그 창을 사용하지 않아 정상 반환했다. 실제 late failure 검사는 `%q`를 넣은 별도 MS5D로 대체했으며 이 변경 리소스를 원본 코드 비교에 사용하지 않는다.

직접 9802 콜백, 전체 RAM, A2/D1/D3 및 포트 순서에 한정한다. 다른 레지스터·SR, 물리적 타이밍, 픽셀 및 전체 게임 부팅 검증은 아니다. 9602 스테이지 구역 콜백, 메뉴 텍스트와 a370 전체 프레임을 거쳐 제어기/메인 루프로 레지스터를 연결하는 작업이 남았다. 전체 목표는 진행 중이다.
