# 타일 디코딩 및 C++ 런타임 패키지 리뷰

- 기준 커밋: ee7acb7. 대상: tile decoder, MS5T packer/loader, 규격, 테스트 및 빌드 명령.
- 사용자 정정: PNG·음원 미리보기는 진단용이며 실제 프로젝트 리소스는 런타임 형식으로 제공한다. AGENTS.md와 GOAL.md에 반영했다.
- gpt-6.1-sol / medium이 확정된 타일 매핑과 C++ 로더 구현을 분담했다. 메인 에이전트가 비트/니블 매핑, 규격, 로더 전체 코드를 검토했다.
- 모든 C 인덱스가 pinned MAME optimize_helper 원본 C++와 일치한다. S 인덱스는 fixed renderer의 nibble 순서와 전체 대조했다.
- 타일 ID를 원본 순서대로 유지하며 원본 색상은 미확인 상태로 명시했다.
- Python 41개 테스트 통과. C++ 테스트는 정상·손상 헤더, 크기·오버플로, CRC, 픽셀 범위, 경계 접근, 실패 시 출력 불변성을 검사하고 통과했다.
- 실제 MS5T 두 파일을 check_tiles에서 성공적으로 읽었다. 스프라이트 524288개, 고정 문자 4096개다.
- 스프라이트 nonzero_tiles=399523, fixed nonzero_tiles=3291. 이는 사용 여부나 개별 캐릭터 수를 의미하지 않는다.
- packer가 중간 포맷 버전·카탈로그 중복/누락·투명 인덱스·입력 해시를 확인하도록 보완했다.
- 전체 게임·팔레트·애니메이션·오브젝트 실행 검증은 아직 아니다. 타일 카탈로그 로더만 구현된 단계다.
