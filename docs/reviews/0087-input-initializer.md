# 입력 초기화 3162 리뷰

대상 기준 커밋: `4d0e010`.

메인이 원본 3162..31d4를 다시 확인하고 초기화 범위, unsigned 선택값 분기, 포인터 테이블 주소와 원본 selector180==0 계약을 검토하여 API를 구현했다. gpt-6.1-sol / medium에 CLI와 원본 실행 비교를 별도 파일로 위임했고, 메인이 결과 코드와 보고서를 리뷰했다.

`initialize_input`은 게임용 입력 12바이트를 지운다. 선택값 0/1에서는 기존 MS5D의 두 포인터 테이블을 읽어 재생·기록 대상 주소를 저장하고 커서·생성 입력·경과 시간을 초기화한다. 선택값 2 이상은 모드만 0으로 바꾸며 기존 재생 상태, raw 입력, 반복 설정을 보존한다. 모든 리소스 검사는 RAM 변경 전에 끝나므로 실패 시 RAM을 보존한다. 포인터는 원본 BE32 주소이며 호스트 포인터로 변환하지 않는다.

단위 검사는 전체 RAM 기대값으로 초기화 범위를 제한하고, 서로 다른 합성 테이블 항목으로 두 선택값의 실제 리소스 사용을 확인한다. 원본 비교는 초기화 121건과 전체 초기화 결과를 이어받은 입력 갱신 120회에서 전체 64KiB RAM이 일치했다. 선택값 0/1/2마다 40회씩 서로 다른 입력 포트 값을 공급했다. 잘못된 RAM·선택값·리소스 및 파일 별칭 17조건에서 기존 파일 보존을 확인했다. 원본 ROM은 변경되지 않았다.
