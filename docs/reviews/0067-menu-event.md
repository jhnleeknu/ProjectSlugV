# 부모 메뉴 콜백 및 정적 오브젝트 재시작 리뷰

대상: `4698454` 이후 이벤트 디스패치 변경.

메인 에이전트가 9b3e, 9430..9540, 9f36, 9fe4/a1ee, 2a28/299c/2782/271c 및 cleanup 하위 함수를 읽고 분기와 필드 효과를 확정했다. 특히 event4의 종료 word 기록 여부가 네 콜백과 나머지 둘에서 다르고, event7의 닫기 전파는 두 콜백에서만 발생한다.

정적 오브젝트 재시작을 단순 콜백 변경으로 축약하지 않았다. 팔레트 해제·연결 좌표 해제/갱신·기존 필드 초기화를 연결했다. 서브에이전트의 object_restart 구현을 검토한 뒤 cleanup 이후 원본이 다시 확인하는 object+10 word 검사를 추가했다. 미지원 연결 리스트 경로와 trap은 상태를 보존한 오류다.

BIOS 점프는 외부 전환으로 명시하고 검증도 해당 명령 실행 전에 멈춘다. 반환 성공이 BIOS 실행 완료를 뜻하지 않는다. A2는 상위 루프에서 필요하여 비교 대상과 API 결과에 포함했다.

검증기 초안이 원본 초기화 팔레트 영역 일부를 누락한 것을 검토에서 발견했다. RAM4d92..5da2 전체를 복사하도록 수정했으며 프로덕션 코드를 잘못된 fixture에 맞추지 않았다.

- 원본975조건: 전체RAM/순서 있는 video 및 watchdog/A2/외부 점프 일치.
- 잘못된 입력6조건: 출력 파일 미생성.
- 단위 검사: 오류에서 RAM/기존 출력/결과 보존, 좌표 cleanup 후 실패 롤백, BIOS 경계 반환.
- `make all test`: 전체 통과.

남은 범위는 헤더 입력 콜백, 자식 콜백, 전체 프레임 루프와 외부 BIOS 전환 통합이다. CPU의 나머지 레지스터/flags·실제 타이밍은 검증 주장이 아니다.
