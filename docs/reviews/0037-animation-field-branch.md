# 애니메이션 필드 조건 분기 분석 리뷰

대상f40b342 이후. 메인에이전트가원본opcode0c의두SNE와공통pointer저장경로를해석했다. 특히조건false에서도fallthrough주소가상태포인터에저장되는점을모델에반영했다.

조건/필드의0·1·128·255,타이머경계와32개선택자prefix의1536조건에서원본전체RAM과carry가일치했다. SCS scratch byte는테스트용으로분리했다. 테이블offset은고정해시원본에서읽으며ROM데이터를Git에추가하지않았다.

테이블전체길이와자연스크립트참조는확인하지않았다. 이단계에서C++지원이나전체선택자검증을주장하지않는다. 다음작업은명시적범위의테이블리소스와실제스크립트참조를연결하는것이다.
