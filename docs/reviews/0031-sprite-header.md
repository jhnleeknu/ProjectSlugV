# 합성 리소스 header 하위 byte 리뷰

대상836289f 이후 변경. 이전 turn은 다중 블록 런타임 구현과 원본 비교를 완료한 progress다.

메인 에이전트가 원본 소비기의D7 비트 배치와 dispatcher 선택 조건을 추적했다. zero 제한이 표시 의미에 필요한 조건이 아님을8192개 원본 CPU 합성 실행으로 확인하고 제거했다. 실제0101/0103 리소스 두 개를 kind2로 추출·검증 대상에 추가했다.

- 원본 ROM 파일은 변경하지 않고 에뮬레이터 메모리에서만 header byte를 교체한다.
- kind1의 이전0100 계약은 유지한다. kind2만 opaque byte를 보존한다.
- 블록 수, 크기, CRC, source 범위, 원자적 실패 검증은 그대로다.
- 로더 및 emitter 단위 테스트는256개 byte 값을 검사한다.
- 이 byte의 다른 엔진 용도를 미확인으로 유지한다. 자연 게임 도달성·unused 판정으로 확대하지 않는다.
