메인은 원본9430, a1ee, a370..a708을 직접 읽고 종료 입력 조건, A2/current 보존 범위, 다시 그리기 순서와 스택 깊이를 정했다. a6da 구현과 late-error/빈 범위 단위검사는 메인이 담당했다. 확정된 헤더 구현/검증, 다시 그리기 CLI, 반복 원본 검증은 gpt-6.1-sol / medium 에이전트3개에 파일별로 분리 위임했다.
