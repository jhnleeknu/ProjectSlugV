# 역방향 스프라이트 슬롯 리뷰

대상:0fdcf1a 이후 변경. 이전 turn은 지연 큐 정렬 구현·원본 검증·커밋으로 진척이 있었다.

메인 에이전트가0x16bba/16cfa의 방향 전환과0x117b2/13b66을 분석하고 확정된 내부 루프를 서브에이전트에 위임했다. diff와 CLI를 읽고 MS5C 런타임 옵션 및 원본 CPU 비교를 통합했다.

- slot 감소는 범위·수평 clip 확인 뒤, Y/X/zoom/tile 쓰기 전에 발생한다. source 열 순서는 그대로다.
- reverse refresh의 cache 비교는 slot>=cached_begin이다. forward 비교와 방향이 반대다.
- 공유 구현의 기존 forward 진입점은 인자·동작을 유지한다.
- 새 CLI 및 MS5C CLI는 잘못된 방향·경계·입력을 출력 열기 전에 거부한다.
- 원본 역방향400조건의 모든 순서 있는 비디오 쓰기와 다음 slot 일치. 이 중 refresh360조건은 MS5C 로더 경로도 비교한다.
- 기존 정방향80+216조건 회귀 일치. 일반 테스트도 통과.

원본 분기표의 첫 번째 단일 직사각형 경로만 구현했다. 전체 스케줄러·flip·다중블록·실제 타이밍·완성 픽셀은 아직 미완료다.
