# f12 입력 호출자 및 D1 전달 리뷰

대상 기준 커밋: `41697c2`.

메인이 원본f12..f38의 갱신 신호 초기화·입력 호출 순서·오브젝트 필드 조회를 분석하고,31d6의 D1.word 변화까지 추적하여 C++ API를 구현했다. gpt-6.1-sol / medium에는 CLI, 원본 비교, 후속 callback 참조 목록화를 분리 위임했다. 메인이 실제 코드와 원본 명령 근거를 검토했다.

f12는 갱신 신호0016을001a로 복사한 뒤0016과4ca2.word를 지운다.31d6→b68 뒤 오브젝트+76을 읽고,0이면f54 아니면f3c 경계로 반환한다. 변경 영역과 오브젝트 필드가 겹쳐도 입력 처리 이후 값을 사용한다. callback 주소와+7a 문맥 값은 원본 주소 정보이며 호출하거나 역참조하지 않는다.

D1.word는 단순히 최종 생성 입력word에서 얻을 수 없다. 재생 이벤트가 토글될 때만 생성 입력word가 D1 상위 바이트를 결정하고, 기다리는 경우에는 입력 D1 상위 바이트가 남는다. 마지막 P2 눌림 edge가 D1 하위 바이트다. 이 값을 optional style 인수로 추가하여 기존 호출을 유지했고, 후처리 오류에서도 style 변경을 취소한다.

단위 검사는 신호 초기화, callback 필드와 갱신 영역의 중첩, callback0/비영 분기, 재생 토글 직후/대기의 서로 다른 D1 결과, 늦은 리소스 오류와 잘못된 오브젝트의 전체 상태 보존을 확인한다. `make all test`는 Python73개와 C++ 전체 통과했다. 로그: `artifacts/input_frame_build_test.log`.

API는f3c 또는f54 직전에 멈춘다. callback 실행, 컨트롤러 실행, 외부 스택 변경, 나머지CPU 레지스터와 CCR, 인터럽트 시간축·전체 부팅은 별도 작업이다. 전체 목표는 active다.

원본 비교437조건(독립237+승계200)이 전체 RAM, D1.word와 반환 경계/정보에서 일치했다. 실제 토글48조건과 비토글94조건을 실행 관측했다. 갱신 영역과 겹치는 오브젝트 필드, A6/A7 및 D3 보존을 확인했다. 오류·별칭16조건은 기존 출력을 보존했다. 원본 고정ROM은 변경하지 않았다.
