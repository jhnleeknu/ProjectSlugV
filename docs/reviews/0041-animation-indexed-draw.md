# 상태 선택 표시 명령 검토

기준 커밋 cacd690 이후 opcode10 변경을 메인 에이전트가 검토했다. 확정된 명령 의미의 구현은 gpt-6.1-sol medium에 위임하고 원본 실행 비교와 통합은 메인이 수행했다.

- MOVE.B 상위 바이트 유지, LSL.W 절단, unsigned CMP와 signed 주소 displacement를 확인했다.
- 기존04와 표시 함수 공유 후 원본 ROM 루프 회귀가 일치했다.
- 목록 전체를 임의 해석하지 않고 선택 항목만 읽는다. 저장 포인터를 변경하지 않는다.
- 실패 시 부분 RAM 변경이 없는 것을 검사했다.
- 768조건 원본/C++ RAM·carry·선택주소 비교, 전체 기존 검사, 추가 단위 검사 통과.
- 실제 전체분기스크립트 도달성 및 지원하지 않는 명령은 남아 있다. 단계 완료이며 전체 목표 완료가 아니다.
