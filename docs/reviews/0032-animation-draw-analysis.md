# 애니메이션 표시 경로 분석 리뷰

대상03860ca 이후 분석 추가. 코드로 보이는 모든 바이트를 함수로 단정하지 않고 확인된 분기 표와 생성기 호출부를 연결했다.

메인 에이전트가 해석한 인자 변환을 원본 CPU3072조건으로 대조했다. 좌표 부호 반전은 제어byte 반전XOR 이전 style을 사용하며, 팔레트 선택에는 오브젝트+16 word의high byte와low byte 조건이 함께 쓰인다. 이런 순서 의존성을 의미 모델에 명시했다.

검증은 cd58 진입 전 중단하므로 bank 복원·큐 부작용·애니메이션 시간 흐름에 대한 주장으로 확대하지 않는다. 조기 반환 분기는 정적 확인으로 분리했고 실행 검증 범위에 포함하지 않았다. C++ 구현과 실제 스크립트 연결이 다음 과제다.
