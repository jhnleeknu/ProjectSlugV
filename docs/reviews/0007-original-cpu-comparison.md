# 원본 CPU 실행 기반 초기화·변환 검증

- 기준 커밋: e4dcad5. 메인 에이전트가 0x271c의 모든 helper와 RAM 변환 루프를 해석하고 CPU 비교 도구를 작성했다.
- gpt-6.1-sol / medium에 확정된 바이트 쓰기 사양으로 C++ 구현·테스트만 위임했다. 메인 에이전트가 전체 코드를 대조했다.
- 첫 Unicorn 실행은 기본 CPU 모델 때문에 ADDA.W에서 실패했다. M68000을 명시한 뒤 정상 복귀를 검증했다.
- 실제 ROM 실행 대 C++ 초기화: 261개 오브젝트의 196바이트 전부 일치. 유지해야 하는 바이트를 포함한다.
- 원본 복사 루프 대 Python ROR16: 4566바이트 전체 일치. watchdog 장치는 모델링하지 않고 쓰기만 수용한다.
- 원본 CPU 및 C++ 호출 스택·레지스터 상태까지 같다는 주장은 하지 않는다. 검증된 계약은 오브젝트 메모리 효과다.
- C++ 메모리 경계·기존 바이트 보존·잘못된 입력 무변경 테스트 통과. Python 55개와 기존 타일 로더 테스트도 통과했다.
- 원본 프로그램과 생성 데이터는 추적하지 않는다. 실행 모델과 SHA256·한계를 문서에 기록했다.
