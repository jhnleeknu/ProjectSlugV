# 전체 메뉴 프레임 레지스터 리뷰

대상 기준 커밋: `343cafe`.

메인이 a370..a6d8의 분기와 하위 호출을 확인하고 프레임 구현을 담당했다. 배경 닫기/다시그리기, 현재 메뉴 열기/닫기, 텍스트, 헤더, pending event, 입력 선택, 이동의 전체 D1/D3를 순서대로 연결했다. 기존의 테두리 종료 line 중복 계산은 하위 API 반환값으로 대체했다. 높이0 닫기 경로의 9e94 D3 하위 word 갱신은 별도 반영했다.

서브에이전트는 CLI·단위 검사·원본 비교와 연속 흐름 검증을 담당했고 메인이 실제 diff/fixture/결과를 검토했다. CLI는 선택적인 레지스터 모드에서만 JSON을 확장한다. 입력 D3와 line 모순 및 늦은 실패에서 기존 RAM·포트·결과·레지스터를 보존한다.

- `make -j3 all test`: 종료 0, Python 73개와 C++ 전체 검사 통과, 경고 없음. 로그 `artifacts/menu_frame_registers_build_test.log`.

프레임 API 계약대로 매 진입 A1은 RAM7f16 렌더러다. D1/D3와 RAM의 실제 C++ 출력은 다음 프레임으로 전달하지만 모든 CPU 레지스터/인터럽트까지 연속 모델링한 것은 아니다. 초기 메뉴 RAM 검증과 첫 프레임의 명시적인 레지스터 fixture는 이후 C++ 반환값 전달과 구분한다. BIOS는 c00444 진입 직전에서 정지한다.

a370의 지원 메뉴 경계가 연결됐으며, 제어기 wrapper와 메인 루프의 전체 레지스터 연결은 아직 남았다. 전체 게임 실행, 다른 CPU 상태, 트랩 처리, 픽셀·사운드·물리적 타이밍 완료를 주장하지 않는다.

- `.venv/bin/python tools/verify_menu_frame_registers.py`: 834프레임, 순서 있는 포트 155,889개 통과. 보고서 SHA256 `bb9f90db18860eb32323838f4934aafedc762967f639b6de294fc91246ca3a45`.
- `.venv/bin/python tools/verify_menu_frame_register_sequences.py`: 116프레임, 순서 있는 포트 9,584개 통과. 보고서 SHA256 `46a1403dee75aaad5b9824b22bb7d33b600b4427f592c61b6e9d895014ff0263`.

기본 행렬의 실제 스테이지 콜백 697회와 오류 보존 29조건을 확인했다. 초기화된 하위 메뉴 흐름 10개/298프레임 및 종료 흐름 8개/116프레임은 실제 CLI RAM/D1/D3를 다음 원본·C++ 호출에 전달한다. 후자는 팔레트/좌표를 정리하는 재시작 4회, BIOS 경계 2회와 빈 스택의 다음 프레임 보존 6회를 포함한다. 초기화 이후 RAM 주입은 명시한 두 입력 byte뿐이며 원본 첫 1MiB는 불변이다.
