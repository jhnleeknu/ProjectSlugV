# 인터럽트 열 위치 갱신 리뷰

대상 기준 커밋: `7916c18`.

메인이72fa/1adf8/16cfa의 의존성을 조사해1adf8→187d8이 아직 빠져 있음을 확인했다. 원본32회 전개 코드를 해석하고 C++ 단일 구조체/네 구조체 호출자와 단위 검사를 작성했다. gpt-6.1-sol / medium에 CLI와 원본 검증을 분리 위임했으며 메인이 실제 코드를 검토했다.

bit0 검사보다 bit7 제거를 앞당기지 않고, 음수slot도 bit7을 제거한 뒤 반환하는 순서를 보존했다.32개열의 주소 상위word와값 하위word를 구분하고, unsigned 임시x 비교와 word wrap을 명시했다. 비디오long 쓰기를 검증 기록에서 쪼개지 않는다. wrapper는 네 구조체 순서와 PVC bank 쓰기 및 RAM0010 갱신을 보존한다. D0는 마지막 활성 구조체의y를 반영한다.

원본1,441조건의 전체RAM/전체D0와78,272포트 기록이 일치했다. 전체flags, 각축512개 유효 좌표, 양쪽 주소word의ffff→0000 순환, 경계 구조체주소,16개 활성 조합과다음 호출의dirty 제거를 검증했다.11개 잘못된 주소/크기/파일 별칭에서 출력을 보존했다. ROM 불변도 확인했다.
