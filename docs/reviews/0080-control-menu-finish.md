# 제어 메뉴의 프레임 종료 연결 리뷰

대상: `a4588c1` 이후 변경.

메인이 원본9302/928e/92a8 및 a370의 종료 경로를 분석하고, 종료 꼬리와 열린 메뉴 연결 API, 트랜잭션 단위 검사를 구현했다. gpt-6.1-sol / medium 에이전트에 주소 참조 목록화, CLI/빌드 연결과 원본 반복 비교를 파일별로 위임했다. 메인이 실제 코드·verifier·산출 보고서를 확인했다.

D0는 TST.B로 판정하고 계속 실행은 MOVE.W0이므로 상위 word를 보존해야 한다. 종료 여부는7dfa의 word가 정확히1인지 검사한다.928e는 e84c8로9079를 그리므로 메뉴9332의 font3→6b 변환을 적용하지 않는다. 진입 palette를 보존하고 제어 byte를 지운 뒤 D0=1을 반환한다.

모드0..2에서 a370의 비영 반환은 빈 스택이나 마지막 높이0 root pop이며 D1을 변경하지 않는다. 이 제어 흐름 근거로 연결 API가 초기 스타일을 종료 꼬리에 전달한다. 원본9302 hook의138개 비영 반환에서도 D1 word 보존을 확인했다. 다른 모드는 명시적으로 거절한다. 비영 종료 콜백 역시 호출이 필요한 경우 미지원 오류이며, 임의의 호스트 함수 포인터 실행으로 대체하지 않았다.

모든 API는 후보 RAM과 임시 포트 목록으로 실행한다. 단위 검사는 root pop 뒤 발생하는 콜백/리소스 실패가 RAM/result/ports를 모두 보존하는지 확인한다. 별도 꼬리 검사는 D0 상위 비트, word 종료 값, palette와 byte 감소 경계를 검사한다. CLI는 모든 입력과 출력의 별칭 및 숫자 범위를 검사한다. 메인 리뷰에서 Makefile의 새 테스트 의존성이 다른 테스트 타깃에 붙은 편집 오류를 수정하여 정확한 test 타깃에 연결했다.

검증:

- `make all test`: Python61개와 C++ 전체 통과. 로그 `artifacts/control_menu_frame_build_test.log`.
- `tools/verify_control_finish.py`:880조건, 실제 문자열 출력118회/포트1,180회, 콜백 거절 출력 보존48조건.
- `tools/verify_control_menu_frame.py`:1,027프레임,13개 연속 시퀀스, stage callback697회/포트165,533회, 거절 출력 보존12조건.9136 진입36회와92fc 진입991회를 비교했다.
- 두 비교 모두 전체64KiB RAM, signed D0와 D3 word, 포트 순서 및 원본 mapped1MiB 불변을 확인했다. 연결 검증은 실제 callback A7, BIOS의 꼬리 우회, watchdog3회도 확인했다.
- 꼬리 보고서 SHA256: `b9a16862228a1fb1b959aab7df3450362f2ac33ad37092501ff6459541b14afe`.
- 연결 보고서 SHA256: `a963f297ca0163bf489ad7a282c4554a925af55edca01733414cef66f981d6cd`.

비영 간접 콜백, 지원 외 descriptor/flags, 모든 CPU 레지스터/flags와 외부 스택, 실제 입력 수집·게임 갱신 스케줄링·부팅·픽셀·타이밍은 완료하지 않았다. 분리된 컨트롤러 분기의 최종 진입 통합이 다음 작업이며 전체 목표는 active다.
