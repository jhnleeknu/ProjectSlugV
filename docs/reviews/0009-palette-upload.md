# 팔레트 전송 커널 리뷰

기준 커밋 e2c3593. 메인 에이전트가 원본 0x7320..0x871a의 1024개 명령(256 bclr,256 beq,512 movem)과 C++ 루프를 대조했다. bit7 해제 전 값을 분기 조건으로 쓰고 해제 후 데이터를 복사하는 순서, 깨끗한 destination 보존, 입력 크기 검사를 확인했다.

원본 M68000 실행과 259개 × 16384바이트 전체 일치. API의 disjoint buffer 사전조건을 헤더에 명시한다. wrapper의 첫 word 마스킹은 API 밖이며 문서에서 구분했다. CLI는 동일 파일/inode와 잘못된 길이를 출력 열기 전에 거부한다. 서브에이전트 strict C++11 빌드 및 실패 경로 점검을 보고했고, 메인 에이전트는 일반 프로젝트 빌드와 원본 차등 비교를 실행했다.

또한 원본 0x4718 helper의 signed16 조회 주소 계산을 16개 실제 데이터 probe에서 확인했다. 전체 팔레트 범위·선택 규칙과 하드웨어 동작은 미완료다. 검증 데이터는 artifacts에만 저장하며 ROM에서 파생된 데이터를 커밋하지 않는다.
