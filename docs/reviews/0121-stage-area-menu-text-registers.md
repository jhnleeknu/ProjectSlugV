# 구역 선택·메뉴 텍스트·이동 레지스터 리뷰

대상 기준 커밋: `886b4cf`.

메인이 9602..9768, 9f12/9f36/9f78, 9b26/9b3e, 9d3a/9e1a, a216/a280과 e89da를 확인했다. 구역 콜백의 event6은 일반 메뉴 이동과 두 번의 행 출력을 실행하므로 세 API를 함께 연결했다. 복잡한 의미 분석과 구역/이동 구현은 메인이 담당하고, 확정된 메뉴 텍스트 사양 구현·CLI·독립 비교 도구는 서브에이전트가 담당했다.

- 구역 확인/취소/무동작은 전체 D1/D3를 유지한다. 그리기는 실제 포맷터 반환 style을 사용하며 마지막 9f12에서 D1 상위 word가 지워지는 효과를 반영한다. D3는 모든 문자열 출력 단계를 거친다.
- 숨은 행은 출력 포트가 없어도 D1 하위 byte를 index+1로 바꾼다. 보이는 행은 D1 전체를 지우고, 콜백이 없더라도 항목 argument를 하위 word에 넣는다.
- 전체 메뉴는 제목 측정과 렌더러의 style 변경을 반영한다. 가려진 glyph의 cursor/style 보존, 위치 제어의 D3 전체 초기화도 유지한다.
- 선택적 레지스터 인자와 기존 line이 모순되면 오류다. RAM·포트·레지스터 출력은 성공 시에만 갱신한다. 기본 호출과 CLI 출력 형식은 유지했다.
- `draw_menu_text --item`으로 원본 단일 행 경계를 독립 비교할 수 있다. 새 구역 CLI는 실제 MS5D 리소스를 읽는다. 영상·음악 확인용 형식으로 런타임 데이터를 대체하지 않았다.
- 메인 리뷰에서 숨은 행 단위 검사의 기대값 두 곳을 index가 아닌 index+1로 고쳤다. 구역 검증의 잘못된 selected-group 오류 가정도 수정했다. event5는 해당 선택 그룹을 참조하지 않으므로 event1로 변경했다. 이 오류 검사는 원본 실행 비교와 분리한다.
