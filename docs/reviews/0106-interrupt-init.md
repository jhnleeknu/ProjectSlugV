# 인터럽트 초기화와 기본 콜백 연결 리뷰

대상 기준 커밋: `2fb5e46`.

메인이 c42/3dce의 원본 바이트와 명령을 다시 확인하고 정확한 초기화 주소 및 보존 범위를 구현했다. 기본3dcc RTS도 명시적 외부 스택을 소비하는 API로 연결했다. 사용자는 target이3dcc일 때만 이 함수를 호출하며 임의 콜백을 대체하지 않는다.

- `make all test`: Python73개 및 C++ 전체 검사 통과. 로그 `artifacts/interrupt_init_build_test.log`.
- `.venv/bin/python tools/verify_interrupt_init.py`: 초기화640조건, envelope/기본 콜백35조건, 첫 서비스 연결16조건과 오류/별칭13조건 통과.
- 연결 검증은 실제3dcc를 실행하고 원본23c JSR c8c에서242까지 이어진다. C++ 서비스 입력 A7은 실제 JSR이 만든 값으로 비교한다. 기본 RTS 실제 실행19회를 확인했다.
- 초기화 멱등성/순서 교환과 RAM18 및 다른 bytes 보존을 확인했다. 기존 초기화 범위 밖의 사운드 입력은 명시적으로 준비한다.
- 검증 중 Unicorn의 캐시된 실행이 until 경계를 지나친 경우를 발견했다. PC/레지스터 근거를 확인하고 code hook의 정확한 경계 중단으로 수정했다. ROM은 패치하지 않았고 수정 후 전체 검증이 통과했다.
- 보고서 SHA256 `c3b058b659bbb5e098b2b9229e1d41ba802a8914304b50005f96953d91dc0615`.

전체 부팅, BIOS/RTE/SR/CCR과 물리 장치 시간축은 후속 범위다. 초기화의 로컬 주소 보존 계약과 기본 콜백 경계에서 통합 차단 문제는 없다.
