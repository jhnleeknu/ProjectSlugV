# 영역 조립·PVC 복호화 리뷰

- 기준 커밋: aea4790. 대상: 현재 브랜치의 영역 조립, PVC 변환, 참고 비교 도구와 문서.
- gpt-6.1-sol / medium 두 에이전트가 명시된 영역 조립과 PVC 변환·테스트를 각각 구현했다.
- 메인 에이전트가 전체 구현을 읽고 MAME 로딩·후처리·BYTE_XOR_LE 정의를 추적했다.
- 초기 endian 가정을 소스 근거로 바로잡았다. 최종 구현에는 LE/BE 명시적 선택과 전체 대응 검증을 포함했다.
- Python 알고리즘의 XOR 표, 워드 순열, 블록 순열, 마지막 1MiB/6MiB 이동을 원본과 대조했다.
- 원본 입력 검증 후 조립, 파일 대응·해시 기록, 출력 경로 제한을 확인했다.
- 추출 명령이 조립 manifest와 실제 입력 크기·해시·바이트 순서를 확인하도록 보완했다.
- 단위 테스트 20개 통과. 실제 8MiB 및 합성 8MiB는 pinned MAME C++ 출력과 전체 일치. 각각 BE 경로도 전체 일치.
- 차등 참고 코드는 원본 알고리즘에서 생성하므로 동일 알고리즘 구현 검증이며, 독립 하드웨어 모델이나 에뮬레이터 전체 실행 검증이 아니다.
- ROM과 생성 바이너리는 Git에서 제외한다. BSD-3-Clause 고지를 보존했다.
