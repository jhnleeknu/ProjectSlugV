# 그래픽·사운드 복호화 리뷰

- 기준 커밋: 676b7a5. 대상: CMC 테이블 로더, CMC50/PCM2 Python 구현과 참고 C++ 비교 드라이버.
- gpt-6.1-sol / medium 두 에이전트가 그래픽·사운드 모듈을 분담했다. 메인 에이전트가 전체 구현과 테스트를 읽고 원본 함수 대조 및 실제 실행을 담당했다.
- 키 0x19를 prot_cmc.h, M1 바이트 합을 hashing.cpp/h로 확인했다.
- CMC 데이터 XOR와 주소 XOR의 순서, M1 p1 테이블 역방향 인덱스, PCM2 24비트 wrap을 검토했다.
- 그래픽 memoryview 정수형 뷰는 산술 없이 같은 형식끼리 워드를 복사하므로 바이트 순서를 바꾸지 않는다.
- load_tables는 SHA256을 확인한 소스에서 길이·값 범위를 검증한 배열만 읽는다.
- 단위 테스트 31개 통과. 새 테스트는 크기/키 오류, 고정 타일 순열 전체, 변조된 참고 소스 거부, M1 순열/XOR 순서, 오디오 영역 및 PCM 주소 사례를 포함한다.
- 실제 미디어 출력 5개 전체가 pinned C++ 함수와 일치했다. 결과 SHA256은 media-decryption.md에 기록했다.
- 동일 알고리즘의 언어간 차등 검증이다. 게임 부팅·팔레트·애니메이션·음악 재생 검증은 아직 아니다.
