# 명시적 역어셈블·주소 대응·오브젝트 정적 분석 리뷰

- 기준 커밋: 5fe5e54. 대상: 범위 역어셈블, 주소 resolver, 오브젝트 분석 리포트와 문서.
- gpt-6.1-sol / medium 두 에이전트가 도구와 합성 테스트를 구현했다. 메인 에이전트는 원본 코드 해석과 전체 도구 리뷰를 담당했다.
- Capstone truncated-buffer 문제를 실제 13fc/4ef9 사례에서 확인하고 padding으로 필요 길이 판정 후 범위 밖 명령을 제외하도록 했다. 회귀 테스트 통과.
- 주소 resolver의 초기 짝수 뱅크 제한은 원본 수식이 보장하지 않아 제거했다. 알려지지 않은 뱅크 상태는 None으로 남긴다. 홀수 뱅크의 실제 실행은 미검증으로 문서화했다.
- 0x268a 데이터 테이블과 0x2790 초기화/0x2aac 디스패치 명령을 수동 대조했다. 노드 주소·콜백 포인터·설정 word·80슬롯 범위를 자동 리포트로 보존했다.
- 콜백 이후 현재 A6의 다음 포인터를 읽는 순서, A5 재설정, 최초 A7 보존을 기록했다.
- 프로그램 해시를 확인하고 분석은 특정 해시에만 적용한다.
- Python 55개 테스트 통과. 분석 결과는 정적 해석이며 에뮬레이터 실행이나 완성된 C++ 오브젝트 엔진을 주장하지 않는다.
