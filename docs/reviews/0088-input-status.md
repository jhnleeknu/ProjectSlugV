# b68 입력 후처리 리뷰

대상 기준 커밋: `38179f5`.

메인이 원본b68..bb4를 다시 읽고 8비트 덧셈, bit3→0 갱신 순서, 슬롯 강제값과 전체 조회 창을 확인하여 C++ API와 통합 함수를 구현했다. gpt-6.1-sol / medium에는 추출기, CLI, 원본 비교를 각각 독립 파일로 위임했다. 메인이 코드와 검증 보고서를 리뷰했다.

작은 표16바이트만 보존하면 슬롯12 이상에서 원본과 다르다. b58..c58의256바이트 전체를 기존 MS5D로 포장했고 명령 바이트와 겹치는 부분도 변경하지 않는다. 자연 상태의 슬롯 의미·도달 범위는 미확인이다. 슬롯251/252의 인덱스255/0 wrap, 원본pending low bits 소모와 high bits 유지, 슬롯1 강제 설정을 검증했다. step_input은31d6 다음b68을 호출하며 늦은 리소스 오류에서도 앞선 RAM과 read_count 변경을 취소한다.

원본 전체 RAM 비교는 독립576조건과 통합160회 갱신에서 통과했다. 모든256 슬롯값을 각 슬롯에서 검사하고, 모든pending/metadata byte, 관련 없는 RAM 초기값, 통합 모드0/1/2와 재생 종료를 포함한다. 원본 MMIO 순서와 read count, 고정 ROM 불변을 확인했다. 오류·파일 별칭12조건도 기존 출력을 보존했다.
