기준 커밋: `3d7d11a` (`codex/f4-f5-acceptance`). 대상은 `docs/WORKFLOW.md`, `AGENTS.md`, `docs/GOAL.md`, `docs/STATUS.md`의 운영 문서 변경이다.

메인은 순서·범위·기존 규칙 일관성을 결정하고 실제 문서를 검토했다. gpt-6.1-sol / medium 작업자 둘이 각각 절차 초안 작성과 읽기 전용 독립 검토를 담당했다. 차단할 문제는 없었다.

`git diff --check`와 문서 간 경로·규칙 일관성을 확인했다. 문서만 변경했으므로 게임 빌드·회귀를 다시 실행하지 않았다. 루트 README는 생성하거나 내용을 추가하지 않았다. 파일 삭제·원격 연결·네트워크 조회·GitHub push는 실행하지 않았다. 지정 목적지와 후속 실행 순서만 기록했다.
